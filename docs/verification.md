以下结果来自 2026-10-29 的本地 CPU 验证，数据全部由生成器产生。它们用于验证软件流程，不代表真实老人的预测效果。

- macOS arm64，Python 3.12.13，CPU。
- 使用 `uv.lock` 锁定环境；验证版本包括 PyTorch 2.15.0、NumPy 2.5.4、pandas 2.3.3、Matplotlib 3.11.2。

测试涵盖关系类型与聚合、T-LSTM 时间衰减、预测时距、序列填充、缺失掩码、训练人员归一化、延迟评分屏蔽、未来记录排除、模型重载、分位数有限且有序，以及修改或删除未来评分后预测不变。另检查前导零和 `NA` 等字符串编号、日期格式一致性及输出覆盖保护。

## 默认合成示例结果

随机种子为 2026；120 人，每人 6–10 次不规则历史记录。训练／验证／测试分别为 84／18／18 人，无人员交叉。每人预测 90、180、365 天，测试集共 54 个目标。

训练最多 30 轮，实际在第 9 轮结束，保存第 4 轮的最佳验证模型。验证 pinball loss 为 0.256623。测试集指标直接从保存的预测 CSV 计算：

| 指标 | 合成数据结果 |
| --- | ---: |
| 中位数 MAE | 0.980609 |
| 平均 pinball loss | 0.303203 |
| 5%–95% 区间经验覆盖率 | 88.89% |
| 5%–95% 区间平均宽度 | 3.871973 |
| 最后一次评分保持不变：MAE | 1.060139 |

分数单位为虚构演示量表的分值。小样本经验覆盖率不构成校准结论，也不能据此宣称临床优势或套用 PPT 中的提升百分比。不同平台的浮点运算可能使结果略有差异。
