# Cognitive Trajectory Prediction v0.1.0 Implementation Plan

> **For agentic workers:** Implement task-by-task with test-first checks, disjoint ownership and final independent review.

**Goal:** Publish the approved runnable synthetic research prototype at NaotoShirogane331/cognitive-trajectory-prediction under MIT.
**Architecture:** Typed per-visit star graph (2 R-GCN layers, width32), time-aware LSTM64, baseline-relative ordered five-quantile head conditioned on forecast horizon. CSV tables feed train-only preprocessing, person-disjoint splits and CPU training.
**Tech Stack:** Python3.12, PyTorch, NumPy, pandas, Matplotlib, pytest, uv lock.
**Spec:** User-approved plan is captured by the constraints and tasks below.

## Global Constraints

Quantiles .05/.25/.50/.75/.95; synthetic seed2026; 120 people with6–10 irregular historical visits; target horizons90/180/365days after each person's last visit. Split people70/15/15. Adam .001, batch16, max30epochs, patience5 based on validation pinball. Separate dt_days and horizon_days. No future score or features may enter historical input or normalization; score availability checked at origin. Missingness separate from zero. Example scores0..30 are a fictional scale, not MMSE/MoCA. Media only indexed. No copying GPL implementation; independently implement published equations and cite papers. Public artifacts only source, synthetic fixtures and docs. No edits to other repositories or PPT.

## Review Focus

1. Unavailable historical scores, future added visits and target-label changes cannot affect inference input.
2. Duplicate same-day sessions require disambiguation; IDs preserve leading zeroes; unsafe asset paths rejected.
3. Train-only preprocessing never reads validation/test values or later-than-origin information.
4. Padding and missing entries cannot affect valid temporal state; every relation and elapsed interval matters.
5. Save/reload consistency, unlabeled inference, finite/ordered quantiles and actual training update.

## Task 1: Data tools (data.py, synthetic.py, tests/test_data.py)

Read schema.py for exact FEATURE_COLUMNS/GROUP_DIMS.
Canonical visits.csv: person_id,visit_id,visit_date(ISO date),session_id,score_available_date, all FEATURE_COLUMNS. Assessment other than score is assumed available on visit_date. score availability missing when score missing, otherwise >=visit_date. Features are numeric or blank; historical score must be finite and0..30 when present.
Canonical assets.csv: person_id,visit_id,modality,path (relative path); optional visit_date/session_id for joining when visit_id absent. Canonical targets.csv: person_id,origin_visit_id,target_date,target_score(optional; ignored at prediction).
Assets synthetic paths need not exist; they are explicitly fictional metadata. Do not create fake media. Checks report index validity separately from file existence.
Public API:
- synthetic.generate_data(output: Path, n_people=120, seed=2026) -> dict counts, writes three CSVs and synthetic provenance JSON. n_people>=10.
- data.load_tables(directory:Path) -> (visits,assets,targets) DataFrames; allow target_score column absent, preserve string IDs.
- data.check_data(directory:Path) -> dict with errors:list[str], warnings:list[str], counts:dict; no mutation. Unlabeled targets permitted.
- data.prepare_data(source:Path, output:Path) -> report; canonicalize dates, sort records, associate assets by person/date/session when necessary, write normalized tables and report. Conflicts raise ValueError with useful information, no guessed joins.
- data.make_splits(visits:DataFrame,seed=2026) -> dict train/validation/test lists of person IDs.
- data.fit_preprocessor(visits,targets,train_ids) -> Preprocessor.
- Preprocessor.to_dict() -> JSON serializable dict; Preprocessor.from_dict(dict) -> instance.
- data.build_samples(visits,targets,preprocessor,person_ids=None,include_labels=True) -> list[dict]. Each sample is ONE target date: x np.float32[T,14], missing np.bool_[T,14] (True missing), dt_days np.float32[T] first0, baseline float(raw latest available score), horizon_days float, person_id/origin_visit_id/origin_date/target_date strings; target_score float only include_labels=True. With include_labels=False do not read any target_score value. Require >=1 available score else clear ValueError; filter visits <=origin within person; mask unavailable score; canonical chronological order. dt only between retained visits. All stats fit only train people's historical features as known at their origins.
Tests before implementation: deterministic generator; person split; index conflicts; future/target contamination; delayed-score masking and baseline; missing versus0; train-only stats; serde.

## Task 2: Model (model.py, losses.py, tests/test_model.py)

Public API CognitiveTrajectoryModel(rgcn_hidden=32,temporal_hidden=64), forward(x[B,T,14],missing[B,T,14],dt_days[B,T],lengths[B],baseline[B],horizon_days[B])->quantiles[B,5]. Native PyTorch only.
Group-specific input encoders concatenate standardized values and missing flags. Five nodes: shared learned center, four feature nodes. Edge relation r maps center<->node(r+1); one matrix per type, sharing direction. Per-destination/per-relation mean; independent W0 self transform; two32dim layers/ReLU. Center sequence to T-LSTM.
T-LSTM decomposes previous c into short=tanh(Wd c+bd), long=c-short; short discount=1/log(e+dt_days/30), recombine then usual input/forget/output/candidate update. Padded steps preserve h/c. Horizon only in readout: concat h and log1p(horizon_days/30), median=baseline+residual; positive softplus gaps make q05<q25<q50<q75<q95. No outcome clipping disguised as calibration.
losses.pinball_loss(predictions[B,5],targets[B]) -> scalar using QUANTILES. Input validation for malformed shapes, non-finite valid entries, invalid dt/horizon; missing/padded values sanitized before encoders.
Tests before implementation: hand-computed loss; relation-specific aggregation (expose RelationalGraphConv if useful); temporal discount; padding invariance; missing garbage invariance; ordered finite outputs; gradient update.

## Task 3: Training and CLI (root owns pipeline.py, cli.py, plotting.py and integration tests)

- train_model(data_dir,output_dir,epochs=30,patience=5,batch_size=16,learning_rate=.001,seed=2026) -> summary dict. Save model.pt,preprocessor.json,config.json,splits.json,training_history.csv,training_summary.json; best validation pinball checkpoint. torch.set_num_threads(1); CPU.
- predict(data_dir,model_dir,output_path,split=None) -> DataFrame. Ignore labels, load safe state_dict; default all people, split optionally saved train/validation/test. Save identifying columns, horizon_days, baseline,q05/q25/q50/q75/q95.
- evaluate(data_dir,predictions_path,output_path) -> metrics dict; one-to-one label join; medianMAE,pinball,90%coverage/width,last-score baselineMAE. Never create comparative accuracy %.
- Plot actual CSV quantiles plus observed history, synthetic annotation; show only as-of-available scores.
CLI ctp generate --output --n-people --seed; prepare --input --output; check --data; train --data --output --epochs --patience --batch-size --learning-rate --seed; predict --data --model --output [--split]; evaluate --data --predictions --output; demo --output [--n-people --epochs --seed]. demo generates/prepares/trains/predicts TEST/evaluates/plots, writes summary. Nonempty output directories protected from accidental overwrite unless explicitly supported resume/force.
